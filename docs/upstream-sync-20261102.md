# 本家 Ver.261102-2 の取り込みとApple版の確認

2026-11-02に [Imaha486/PC98PLAYER](https://github.com/Imaha486/PC98PLAYER/commit/bbff15f2fbc5bfd902f672b35399051c2a65cedc) の `Ver.261102-2` (`bbff15f`) をMac版・iOS版へマージしました。

## 取り込んだ変更

本家のCPU・DOS・音源・AVSDRV・SCSI CD・PEGCなどの更新を共通コアへ反映しました。256色は本家の実装へ揃え、BIOS ROM不要のHLE方式を維持しています。Apple固有のデータ保護用ファイルオーバーレイとVF1〜VF5のBIOSキー入力は残しています。

- Mac：本家の機種判定要求に対し、256色／16色を選ぶダイアログを表示。INIの `PC9821=1` または `VideoColors=256` による指定も使用できます。
- iOS：オプションの16色／256色を優先。本家で追加された `pc9821` と従来の `video_colors` の両方を設定し、16色指定がINIのPC9821設定に負けないようにしています。
- 両版：本家の `fb_h` に合わせ、640×400／640×480のフレームを全行転送。Macのウインドウ比率とiOSのマウス移動倍率も表示高へ追従します。iOSは筐体内へ比率を維持して収めます。
- NAS／ローカルのデータ選択、iOSの一時キャッシュと独立したセーブ領域、既存のキーボード・全画面操作を維持しています。

## 再検証用のiOS Debug起動引数

`--cached-game ID --verify-game-frames 9000` で、一時キャッシュ内の指定ゲームに決めた入力を送り、`Documents/compatibility-result.json` と `compatibility-frame.png` を生成します。通常の音声出力は止め、生成PCMの最大振幅だけを記録します。Releaseビルドにはこの検証処理を含めません。

```sh
IOS_BUILD_ROOT=build/upstream-261102 IOS_BUILD_NUMBER=7 ./build_ios.sh
IOS_BUILD_ROOT=build/upstream-261102 ./tools/test_ios_simulator.sh DEVICE_UDID
```
